# Synthesized assets — ROM-FORGE synthesizer v0
First technogenerative pass. Every tile from the two homebrew corpora is embedded
in a 67-dim polysemantic feature space (64-bin RGB histogram + entropy + edge
density + alpha fraction), k-means clustered, then new tiles are cut-and-splice
crossed from cluster pairs. All outputs are SHA256-verified NOVEL (no corpus copy).
Full parentage in manifest.json. Trained exclusively on open-source homebrew.
